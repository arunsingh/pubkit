# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be decent. Assume good faith, critique the code rather than the
person, and take the disagreement to the technical merits.

Report unacceptable behaviour to the maintainer via a GitHub security advisory
or a direct message. Reports will be handled discreetly.
